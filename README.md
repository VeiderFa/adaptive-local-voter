# Adaptive Voter Model — reproduction code

Code and precomputed results for:

> **How Recommendation Algorithms Shape Social Networks: An Adaptive Voter Model Approach**
> Fabian Veider, Georg Jäger, Bao Quoc Tang
> *npj Complexity* (Nature Portfolio, 2026). DOI: [10.5281/zenodo.23193665](https://doi.org/10.5281/zenodo.23193665).

This repository reproduces every simulation figure in the manuscript. It is a
cleaned, minimal extraction of the authors' working repository (no scientific
logic was changed).

## Repository structure

```
src/avm/
  avm_two_state_v2.py   # core AVM simulation (Numba JIT)
  sweep.py              # parameter-sweep driver / aggregation
  plots.py              # manuscript figure code 
scripts/
  run_sweep.py          # generate results_*_enhanced_sweep_n*.pkl
  make_figures.py       # regenerate manuscript figures from the pkl files
  download_data.py      # fetch precomputed pkl files from Zenodo
notebooks/
  AVM_Recent_v2.ipynb   # original interactive pipeline (outputs stripped)
data/                   # Zenodo pointer + description (pkl not in git)
figures/                # reference figures as used in the manuscript
tests/                  # fast smoke test
Makefile, setup.sh, requirements.txt, pyproject.toml
```

## Install

**Python 3.12 is required** — numba/llvmlite (pinned in `requirements.txt`)
do not build on 3.13+.

```bash
./setup.sh                    # creates .venv with Python 3.12 and installs pinned deps
source .venv/bin/activate
```

or manually:

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
```

## Quick start

```bash
# 1. fetch precomputed sweep results from Zenodo
python scripts/download_data.py --out data

# 2. regenerate all manuscript figures (writes to figures/)
make figures

# 3. fast test (no data required)
make test
```

Runtime (reference machine, plotting only): seconds to a few minutes per
topology; the WS global `pkl` load is the slowest. Full sweeps take hours
(see below).

### Regenerating the data from scratch

```bash
make sweep-ER    # ~ hours; 11 phi x 11 k x 100 runs
make sweep-WS    # includes homophily 1.0, 0.9, 0.7, 0.5
make sweep-BA
```

The simulations use **100 realisations per parameter set** (matching the
manuscript).

**Figure fidelity.** Regenerated figures reproduce the manuscript
quantitatively but are not pixel-identical: the archived reference figures were
rendered with an older matplotlib/font stack.

## Data

- **Source:** generated by this code (Monte-Carlo simulation); no external data.
- **Canonical run:** the `Sweep_<NET>_Undirected_Magnetization` batches (Dec 2025,
  100 realisations) are the single canonical source for all manuscript figures.
  Earlier `*_Enhanced` batches are not required.
- **Archive:** Zenodo DOI [10.5281/zenodo.23193665](https://doi.org/10.5281/zenodo.23193665)
  (`data/README.md`, `scripts/download_data.py`; ~720 MB of `.pkl`).
- **License:** code MIT; data CC BY 4.0 (as archived on Zenodo).
- **Third-party material:** none included.
